# Upstream sources

Every jor skill is a copy, not a link. This table records where each one came from and the exact upstream commit it was copied from, so upstream changes can be reviewed by hand against that point. Commits are the latest commit touching that path on `main` as reported by the GitHub API on 2026-10-26; the copied files were checked byte-for-byte against the raw files at those commits.

jor-stack is MIT. See [LICENSE](LICENSE). Copied skill text stays under the upstream MIT licenses in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

v0.1.1 (2026-10-27) stopped slash-only skills from invoking each other: mid-task a skill reads the other skill's file and follows it, and the user's next step is a `/jor-...` command the agent recommends. It also removed the remaining browser options that named Playwright, Puppeteer, or Cypress. Browser checks stay on Chrome DevTools MCP.

Current workflow changes add automatic `jor-peer-review` to implementation and bugfix closeout, keep browser checks opt-in, and make full `jor-review` optional for large changes after any requested browser review and fixes. PR-body preparation and private output locations retain their boundaries. Descriptions use plain names instead of angle-bracket placeholders for Codex validator compatibility.

## Updating from upstream

Upstream updates are a manual review. Diff the upstream path from the recorded commit to its current `main` (for example `https://github.com/mattpocock/skills/compare/<commit>...main`), merge by hand only what you want, then update the commit in this table. Never overwrite a jor skill with a fresh upstream copy.
